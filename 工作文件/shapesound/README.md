# 形声 · 画出来的音乐

一件"画线即作曲"的网页可视化乐器。玩法与界面布局参考了 playmusictheory.net/play（作者 Tala Rae Schlossberg）：在纸上画线，播放头从左往右扫过，碰到线条就发声。本项目的代码、文字、配色与图标均为独立编写。

## 运行
**给人用的成品是 `最终成品/形声.html`**：一个文件，双击用 Chrome 或 Edge 打开即可，不用安装、不用联网，可以直接发给别人。

## 修改代码
本文件夹（`工作文件/shapesound/`）里是拆开的源文件，改代码改这里；改完在本文件夹运行：

    python build.py

就会重新生成 `最终成品/形声.html`。不要直接改成品文件，下次生成时会被覆盖。开发时也可以直接双击本文件夹的 `index.html` 预览（效果和成品一样）。
（如果 MIDI 键盘连不上，可在本目录运行 `python -m http.server 8000`，再打开 http://localhost:8000）

## 界面
- **左侧工具栏**：当前作品名、＋ 新建空白、⇪ 导入谱子、♪ 示例曲（第一次打开会自动弹出）、我的作品、保存、录音；画笔、橡皮、撤销、重做、清空、随机换音色；16 种颜色 = 16 种乐器；换配色、音符网格、换背景（点一下在纸 / 天空 / 夜之间切换，长按或右键才选自己的图片）。网格开关和背景是全局设置，换到哪首谱都保持不变。新手引导：先是「音符网格」按钮闪，点过之后轮到「随机换音色」闪，各自点过一次就不再闪
- **中间**：画纸（默认是白纸，打开网格能看到每行音名）
- **乐器面板**：调（附迷你钢琴显示音阶，点琴键也能换调）、音阶、音域、八度、微调、量化、摇摆、节拍器、MIDI 输入、导出 WAV / MIDI
- **走带**：Pages 时间线、单页循环、大屏曲谱、回到开头、播放 / 暂停、速度条 + BPM、Tap 测速、节拍灯、「显示」1 / 2 / 3、「伴奏」• 贝斯 / •• 鼓 / ••• 琶音（按钮带文字，各自开关，可叠加）

## 功能清单
| 功能 | 说明 |
|---|---|
| 示例曲 | 11 首点开即播，分三类：简单儿歌（小星星、两只老虎轮唱、生日快乐、铃儿响叮当）、复杂编曲·挑战（原创《星海远征》15 种乐器全部上场、8 页、高潮同时十几个声部；卡农 8 页真正的轮奏、6 段变奏；欢乐颂完整主题奏两遍、一开场就是乐队；原创电子《夜跑》8 页、8-bit 和电吉他齐奏副歌，都是多乐器分声部、一页一页叠加）、好玩（8-bit 小冒险、画一只小猫、组员用照片描线做的《奶龙捧腹大笑》）。默认不显示网格，每首附一条「试试」引导；全部为公有领域曲目或原创 |
| 画线发声 | 竖直位置 = 音高；横线长音、斜线琶音、竖线和弦；播放头与线条的交点实时标出 |
| 调 / 音阶 | 12 个调 × 11 种音阶：大/小调五声、大调、自然小调、和声小调、Dorian、Phrygian、Lydian、Mixolydian、布鲁斯、半音阶 |
| 16 种乐器 | 键盘、拨弦、钟、马林巴、长笛、弦乐、风铃、贝斯、8-bit、铜管、管风琴、竖琴、电钢琴、合唱、电吉他、鼓组，全部用 Web Audio 实时合成。电吉他是重失真的独奏音色：先用 Karplus-Strong 算法模拟一根被拨响的琴弦，再过失真和音箱模拟。鼓组按线条在音域里的高低敲不同的鼓：底鼓、通鼓、军鼓、闭镲、开镲、吊镲 |
| 节奏 | 一小节 8 拍，手机和电脑每张画纸都为 2 小节（16 拍）；120 BPM 时一圈 8 秒。量化 1/4 ~ 1/32（含三连音），摇摆 关 / 轻 / 中 / 重，节拍器 |
| 伴奏（三个圆点） | • 贝斯：每拍一下主音（C3 附近，跟随调）；•• 鼓：偶数拍底鼓、奇数拍军鼓、外加闭镲；••• 琶音：在镲点上循环 8 音乐句，大调用 1-3-5-6-1′-6-5-3，小调家族换成 1-♭3-5-♭7-1′-♭7-5-♭3。三者独立开关、可叠加，导出 WAV / MIDI 时一并包含 |
| 配色 / 背景 | 3 套配色（明亮、国色、霓虹），背景可选纸 / 天空 / 夜 / 自选照片 |
| 输入 | Web MIDI 键盘；电脑键盘 A–; 和 Q–P；播放时弹的音会按量化画进循环 |
| 显示模式 1 / 2 / 3 | 1 画线模式；2 像素模式：画纸变成方格（每列一步，格子保持正方形），线碰到的格子被填满，播放头扫过时格子发亮、停一步、再用 1.5 步淡出；3 舞台模式：4 × 4 格，一格一种乐器，点格子放照片，播放时某种乐器在响它的格子才露出照片（没放照片的格子会变亮）。和原作一样，3 只在手机宽度（< 760 px）出现，窗口变宽会自动回到 1 |
| Pages 时间线 | 打开后在下方出现时间线条：每页一张画（一页 = 一圈），点「N 小节」在 1 / 2 / 4 / 8 之间切换这一页放几个小节；＋ 新页、复制、删除；顶上标尺数小节，红线是播放位置。可以叠加多条时间线一起播，其他时间线正在播的页会淡淡地显示在画纸上；时间线可折小、可删除。Pages 按钮只管显示时间线；放不放下一页由旁边的「单页循环」按钮决定：开着时只循环眼前这一页，关掉时一页放完接着放下一页（全局设置，默认关） |
| 导入谱子 | 粘贴简谱文字（1–7、0 休止、- 延长、. 附点、_ 八分、' 高八度、, 低八度、#/b 升降、[135] 和弦、1=G 定调、♩=90 速度、@贝斯 开新声部），或选 MusicXML（.musicxml / .xml / .mxl）、MIDI（.mid）文件，也可以直接拖进网页。每个声部按乐器名或 GM 音色配一种颜色（MIDI 第 10 通道和打击乐声部用鼓组）；自动设好调、音阶（大调 / 小调 / 和声小调…，临时升降号太多就用半音阶，保证每个音都准）、音域、八度、量化和速度；移调乐器按实际音高、连音线合并；一页 16 拍，多页自动打开时间线；导入后存进「我的作品」。想把五线谱照片 / PDF 识别成音符，需要先用 MuseScore 或 Audiveris 转成 MusicXML |
| 照片描线 | 在「导入谱子」里选一张照片（或直接拖进网页），自动把轮廓描成线条，变成一幅会响的画：可调「线条多少」（约 30～150 条）、颜色（按照片里那一处的颜色选乐器，黑白灰的线用键盘；或全用当前乐器）、比例（保持照片比例 / 铺满画纸），实时预览。生成后用大调五声音阶、3 个八度，怎么画都和谐，存进「我的作品」 |
| 大屏曲谱 | 底部的大屏按钮让画纸铺满整个屏幕（支持的浏览器会顺便全屏），只留一排浮动小工具条：播放、画笔、橡皮、撤销、换颜色、退出；手机上也能画。按「退出大屏」或 Esc 回到普通界面 |
| 新手引导 | 第一次来、关掉欢迎弹窗后自动开始：一步一步圈出常用和好玩的按钮（颜色、画纸、播放、随机换音色、网格、示例曲、导入、伴奏、Pages、单页循环、大屏、我的作品、帮助），每步一句说明；可以上一步 / 下一步 / 跳过，键盘 ← → Esc 也行。手机上看不到的按钮自动跳过。在「怎么玩」里能重新看一遍 |
| 我的作品 | 作品保存在浏览器里，可随时切换、改名、删除、导出 / 导入 .json。已保存的作品之后自动保存；示例曲本身不能被改，一改就自动另存为新作品「xx（我的改编）」；没保存的新作品切换时自动存成「草稿」（最多留 10 个），不会丢 |
| 导出 | WAV（离线渲染出一段可无缝循环的音频）、MIDI（标准 MIDI 文件，每种乐器对应一个 GM 音色，鼓组写进打击乐通道，16 个通道用满）、实时录音 |

## 技术要点（写报告时可以用）
- **线条 → 音符**（`computeEvents`）：把一圈循环按量化分成 N 步，算出每条线在每一步覆盖到的音阶行；同一个音在相邻步里连续出现，就合并成一个长音。
- **精确定时**（`tick` / `scheduleStep`）：用 lookahead scheduler，每 25 ms 提前 120 ms 按 AudioContext 的时钟排好音符，不会像 setTimeout 那样抖动。画面根据已经排好的步实时插值出播放头的位置。
- **合成**（`voice`）：加法合成（键盘、马林巴、风铃、管风琴、竖琴）、减法合成（拨弦、弦乐、贝斯、铜管）、FM 合成（钟、电钢琴）、Karplus-Strong 拨弦 + 失真 + 音箱模拟（电吉他）、带颤音和气声噪声的长笛、共振峰合唱、方波 8-bit、噪声 + 扫频正弦的鼓组；混响用程序生成的脉冲响应做卷积；总输出先压缩、再过一道限幅器，十几个声部同时响也不破音。
- **导入**（`importer.js`）：三种格式先解析成同一种「乐谱」（声部 → 音符的开始拍、时值、MIDI 音高），再统一换算：按音高分布选调和音阶、用最小的音域装下所有音、选能对上 98% 以上节奏的最粗量化格子，最后每个音画成一段横线。.mxl 是 zip，用浏览器自带的 DecompressionStream 解压；MIDI 按 SMF 格式逐字节解析（支持 running status）。全部离线完成，不依赖任何库。
- **照片描线**（`photo.js`）：思路参考 LingDong 的 linedraw（MIT 许可）。照片缩到 360 像素以内 → 灰度 → 高斯模糊 → Sobel 梯度 → 非极大值抑制 → 双阈值连接（Canny 边缘检测）→ 把边缘像素沿 8 邻域串成折线（先从线头走，剩下的是闭合的环）→ Ramer–Douglas–Peucker 简化 → 按长度只留最长的若干条。每条线在两侧取颜色，挑颜色最鲜艳的一侧，按当前配色找最接近的乐器。全部自己实现，一张图 30～60 毫秒。
- **导出**：WAV 用 OfflineAudioContext 渲染两遍循环，取第二遍，这样混响尾音会自然接回开头，循环拼接没有断口；MIDI 按 SMF 格式 0 手写字节编码。
- 纯原生 HTML / CSS / JS，没有任何依赖。源文件结构（`build.py` 会把它们合并成一个单文件成品）：
  - `index.html`：页面结构
  - `style.css`：样式
  - `js/core.js`：音乐数据、状态、线条→音符、音频合成、伴奏、调度器
  - `js/canvas.js`：画布绘制、画线/橡皮、实时演奏、乐器面板、显示模式、Pages 时间线
  - `js/app.js`：工具栏、自动保存、录音、导出 WAV / MIDI、悬停提示
  - `js/songs.js`：示例曲
  - `js/library.js`：我的作品（作品库）和启动流程
  - `js/importer.js`：导入谱子（简谱文字、MusicXML / .mxl、MIDI 的解析，以及换算成线条）
  - `js/photo.js`：照片描线（Canny 边缘检测、边缘连成折线、简化）
  - `js/bigscore.js`：大屏曲谱
  - `js/tour.js`：新手引导
  - `build.py`：把上面这些合并成 `最终成品/形声.html`
