# 形声 · 画出来的音乐

一件"画线即作曲"的网页可视化乐器。玩法与界面布局参考了 playmusictheory.net/play（作者 Tala Rae Schlossberg）：在纸上画线，播放头从左往右扫过，碰到线条就发声。本项目的代码、文字、配色与图标均为独立编写。

## 运行
双击 `index.html`，用 Chrome 或 Edge 打开即可。不用安装，也不用联网。
（如果 MIDI 键盘连不上，可在本目录运行 `python -m http.server 8000`，再打开 http://localhost:8000）

## 界面
- **左侧工具栏**：画笔、橡皮、撤销、重做、清空、随机换音色；9 种颜色 = 9 种乐器；换配色、音符网格、换背景；保存 / 打开 / 录音
- **中间**：画纸（默认是白纸，打开网格能看到每行音名）
- **乐器面板**：调（附迷你钢琴显示音阶，点琴键也能换调）、音阶、音域、八度、微调、量化、摇摆、节拍器、MIDI 输入、导出 WAV / MIDI
- **走带**：Pages 时间线、回到开头、播放 / 暂停、速度条 + BPM、Tap 测速、节拍灯、显示模式 1 / 2 / 3、三个圆点伴奏：• 贝斯、•• 鼓、••• 琶音（各自开关，可叠加）

## 功能清单
| 功能 | 说明 |
|---|---|
| 画线发声 | 竖直位置 = 音高；横线长音、斜线琶音、竖线和弦；播放头与线条的交点实时标出 |
| 调 / 音阶 | 12 个调 × 10 种音阶：大/小调五声、大调、自然小调、和声小调、Dorian、Phrygian、Lydian、Mixolydian、布鲁斯 |
| 9 种乐器 | 键盘、拨弦、钟、马林巴、长笛、弦乐、风铃、贝斯、8-bit，全部用 Web Audio 实时合成 |
| 节奏 | 一小节 8 拍，宽屏一张纸 2 小节（16 拍），手机 1 小节；120 BPM 时一圈 8 秒。量化 1/4 ~ 1/32（含三连音），摇摆 关 / 轻 / 中 / 重，节拍器 |
| 伴奏（三个圆点） | • 贝斯：每拍一下主音（C3 附近，跟随调）；•• 鼓：偶数拍底鼓、奇数拍军鼓、外加闭镲；••• 琶音：在镲点上循环 8 音乐句，大调用 1-3-5-6-1′-6-5-3，小调家族换成 1-♭3-5-♭7-1′-♭7-5-♭3。三者独立开关、可叠加，导出 WAV / MIDI 时一并包含 |
| 配色 / 背景 | 3 套配色（明亮、国色、霓虹），背景可选纸 / 天空 / 夜 / 自选照片 |
| 输入 | Web MIDI 键盘；电脑键盘 A–; 和 Q–P；播放时弹的音会按量化画进循环 |
| 显示模式 1 / 2 / 3 | 1 画线模式；2 像素模式：画纸变成方格（每列一步，格子保持正方形），线碰到的格子被填满，播放头扫过时格子发亮、停一步、再用 1.5 步淡出；3 舞台模式：九宫格一格一种乐器，点格子放照片，播放时某种乐器在响它的格子才露出照片（没放照片的格子会变亮）。和原作一样，3 只在手机宽度（< 760 px）出现，窗口变宽会自动回到 1 |
| Pages 时间线 | 打开后在下方出现时间线条：每页一张画（一页 = 一圈），点「N 小节」在 1 / 2 / 4 / 8 之间切换这一页放几个小节；＋ 新页、复制、删除；顶上标尺数小节，红线是播放位置。可以叠加多条时间线一起播，其他时间线正在播的页会淡淡地显示在画纸上；时间线可折小、可删除。关掉 Pages 时只循环眼前这一页 |
| 保存 | 作品存为 .json（含全部时间线、页面和设置），也能打开旧版本存的文件；浏览器会自动保存上次的作品 |
| 导出 | WAV（离线渲染出一段可无缝循环的音频）、MIDI（标准 MIDI 文件，每种乐器对应一个 GM 音色）、实时录音 |

## 快捷键
空格 播放/暂停 · Ctrl+Z 撤销 · Ctrl+Y 重做 · 1–9 选乐器 · Shift+E 橡皮 · G 网格

## 技术要点（写报告时可以用）
- **线条 → 音符**（`computeEvents`）：把一圈循环按量化分成 N 步，算出每条线在每一步覆盖到的音阶行；同一个音在相邻步里连续出现，就合并成一个长音。
- **精确定时**（`tick` / `scheduleStep`）：用 lookahead scheduler，每 25 ms 提前 120 ms 按 AudioContext 的时钟排好音符，不会像 setTimeout 那样抖动。画面根据已经排好的步实时插值出播放头的位置。
- **合成**（`voice`）：加法合成（键盘、马林巴、风铃）、减法合成（拨弦、弦乐、贝斯）、FM 合成（钟）、带颤音和气声噪声的长笛、方波 8-bit；混响用程序生成的脉冲响应做卷积。
- **导出**：WAV 用 OfflineAudioContext 渲染两遍循环，取第二遍，这样混响尾音会自然接回开头，循环拼接没有断口；MIDI 按 SMF 格式 0 手写字节编码。
- 纯原生 HTML / CSS / JS，单文件，没有任何依赖。
