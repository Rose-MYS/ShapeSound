怎么玩

  1. 画线就是作曲。竖线（播放头）从左往右扫，碰到哪条线，哪条线就发声：越高音越高；横线是长音，斜线是琶音，竖线是和弦。
  2. 选调和音阶。打开「音符网格」能看到每一行的音名；网格里只有音阶内的音，怎么画都和谐。
  3. 定速度。拖速度条、输入 BPM，或者跟着拍子连点 Tap；节拍器可以打开听拍子。
  4. 颜色就是音色。十六种颜色对应十六种乐器；最后一种是「鼓组」：画得越低越是底鼓，越高越是镲；接上 MIDI 键盘并打开「MIDI 输入」，播放时弹的音会画进循环里。

底部「伴奏」三个按钮：• 贝斯　•• 鼓　••• 琶音。点一下开、再点关，可以同时开好几个；它们跟着你选的调走。
不知道从哪开始？点左边的 ♪ 示例曲，听一首再改着玩。
有现成的谱子？点 ⇪ 导入谱子：粘贴简谱，或选 MusicXML / MIDI 文件，自动画成线条；也能选一张照片，把轮廓描成会响的线条。
1 / 2 / 3 是显示模式：画线、像素（格子会随播放头亮起）、舞台（每种乐器一个格子配照片，手机宽度才出现）。
最左边的 Pages 打开时间线（只管显示），旁边的 单页循环 按钮决定是只循环眼前这一页，还是一页放完接着放下一页；Pages 里每页一张画，点「N 小节」改这一页放几个小节，＋ 新页、复制、删除；还能叠加多条时间线一起播。
「保存」把作品存进「我的作品」，在那里可以随时切换、改名、删除，或导出成 .json 文件（Ctrl+S 快速保存）。

示例曲

点一首就会自动播放。线越高音越高，横线越长音越长。听完照着「试试」改一改，就是你自己的版本了。你画的东西不会丢：没保存的会自动存进「我的作品」。

我的作品

作品保存在这个浏览器里，刷新、关掉网页都还在。已保存的作品之后的修改会自动保存；没保存的新作品，切换时会自动存成草稿。换电脑或清理浏览器数据前，记得点「导出」备份成文件。

导入谱子

把现成的谱子自动画成线条：每个声部一种颜色，调、音阶、音域、速度都会自动设好，一页 16 拍，多页自动串成时间线。导入的谱子存进「我的作品」。
MusicXML（.musicxml / .xml / .mxl）或 MIDI（.mid）。也可以直接把文件拖到网页上。

或者从照片描线

任何照片或图片都行：把轮廓描成线条，变成一幅会响的画（不是识别图里的音符）。也可以把照片直接拖到网页上。

或者输入简谱

1–7 音　0 休止　- 延长一拍　5. 附点　1_ 八分音符　1__ 十六分　1' 高八度　1, 低八度　#4 b7 升降　[135] 和弦
1=G 定调　♩=90 速度　另起一行写 @贝斯（或 @长笛、@鼓…）开始一个新声部，名字决定用什么乐器　第一行不带数字的文字当作标题
想把照片或 PDF 里的五线谱当成音符识别出来：网页没法直接做。可以先用免费的 MuseScore（导入 PDF）或 Audiveris 识别，导出成 MusicXML，再从这里导入。
