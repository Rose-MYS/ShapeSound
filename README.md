# 形声 ShapeSound · 画出来的音乐

一件"画线即作曲"的网页可视化乐器：在纸上画线，播放头从左往右扫过，碰到线条就发声——线越高音越高，颜色就是乐器。

> 玩法与界面布局参考了 [playmusictheory.net/play](https://playmusictheory.net/play)（作者 Tala Rae Schlossberg）；本项目的代码、文字、配色与图标均为独立编写。

## 马上试试

下载 [`最终成品/形声.html`](最终成品/形声.html)，用 Chrome 或 Edge 双击打开即可。

- 只有这一个文件，不用安装、不用联网，可以直接发给别人
- 第一次打开会弹出示例曲，点一首就能听；之后点左边的 **＋ 新建空白** 自己画

## 能做什么

| | |
|---|---|
| **画线发声** | 竖直位置 = 音高；横线是长音、斜线是琶音、竖线是和弦。12 个调 × 11 种音阶（大调五声、大小调、和声小调、调式、布鲁斯、半音阶），选对音阶怎么画都和谐 |
| **16 种乐器** | 键盘、拨弦、钟、马林巴、长笛、弦乐、风铃、贝斯、8-bit、铜管、管风琴、竖琴、电钢琴、合唱、电吉他、鼓组，全部用 Web Audio 实时合成；还能一键「随机换音色」 |
| **示例曲** | 11 首，分三类：简单儿歌、复杂编曲（多乐器、多声部，最多 8 页）、好玩。示例曲本身不会被改动，改了会自动另存为你的作品 |
| **Pages 时间线** | 多页串成一首完整的曲子，还能叠加多条时间线一起播；「单页循环」按钮决定只循环当前页，还是一页接一页往下播 |
| **导入谱子** | 粘贴**简谱文字**，或导入 **MusicXML（.musicxml / .xml / .mxl）**、**MIDI（.mid）**，自动按声部配乐器、选调和音阶、画成线条 |
| **照片描线** | 选一张照片，自动把轮廓描成线条，变成一幅会响的画（按形状发声，不识别照片里的音符） |
| **伴奏** | 贝斯、鼓、琶音三种自动伴奏，跟着调走，可以叠加 |
| **我的作品** | 作品保存在浏览器里，随时切换、改名、导出 / 导入 .json；没保存的会自动存成草稿 |
| **导出与输入** | 导出 WAV（可无缝循环）和 MIDI，实时录音；支持 MIDI 键盘和电脑键盘弹奏 |
| **其他** | 3 套配色、4 种背景（可用自己的图片）、像素模式、手机上的舞台模式、新手引导 |

## 仓库结构

```
├── 最终成品/
│   └── 形声.html          ← 给人用的单文件成品（由 build.py 生成，不要直接改）
├── 工作文件/shapesound/   ← 源代码
│   ├── index.html         页面结构
│   ├── style.css          样式
│   ├── js/core.js         音乐数据、线条→音符、音频合成、伴奏、调度器
│   ├── js/canvas.js       画布、画线 / 橡皮、乐器面板、显示模式、Pages 时间线
│   ├── js/app.js          工具栏、保存、录音、导出 WAV / MIDI
│   ├── js/songs.js        示例曲
│   ├── js/library.js      我的作品、启动流程
│   ├── js/importer.js     导入简谱 / MusicXML / MIDI
│   ├── js/photo.js        照片描线
│   ├── build.py           把源文件合并成单文件成品
│   └── README.md          详细的功能说明和技术要点
└── 工作记录/              计划与任务记录
```

## 修改与构建

改 `工作文件/shapesound/` 里的源文件，然后在该文件夹运行：

```bash
python build.py
```

就会重新生成 `最终成品/形声.html`。开发时也可以直接双击 `工作文件/shapesound/index.html` 预览。如果 MIDI 键盘连不上，在该文件夹运行 `python -m http.server 8000`，再打开 http://localhost:8000 。

纯原生 HTML / CSS / JavaScript，没有任何第三方依赖。功能细节和实现原理（线条怎么变成音符、精确定时、各乐器的合成方法、导入和描线的算法）见 [工作文件/shapesound/README.md](工作文件/shapesound/README.md)。
